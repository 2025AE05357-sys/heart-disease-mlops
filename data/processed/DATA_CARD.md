## Processing

| Step | Rule |
|---|---|
| Integrity | Every raw file must match its SHA-256 in `data/raw/MANIFEST.json` |
| Parse | `?` becomes a missing value |
| Recode | Zeros in `trestbps`, `chol` mean "not measured" and become missing |
| Gate | Rows outside the ranges or codes in `configs/data.yaml`, or without a diagnosis, go to `rejected.csv` with a reason |
| Fail | A site fails if its row count differs from the config or more than 5% of its rows are rejected |
| Target | `target = 1` if `num_raw > 0` (any disease severity), else `0` |
| Not done | No imputation or scaling: both happen inside the model pipeline |
